# exerciții de olimpiadă

exerciții de programare din Republica Moldova, scrise în C++.

## rulare

din directorul proiectului, compilează exercițiul dorit cu un compilator C++:

```sh
g++ ex1.cpp -o ex1
./ex1
```

pe Windows rulează `ex1.exe`. unele exerciții citesc fișiere `.in` din directorul curent și pot scrie în fișiere `.out`, așa că verifică numele fișierelor din cod înainte de rulare.
